# Arduino Nano Matter
A personal playground repo for learning and experimenting with the **Arduino Nano Matter** — sketches, notes, and small projects as I explore the board and the Matter IoT standard.

## Device Specification

The Arduino Nano Matter pairs Arduino's familiar Nano form factor with Silicon Labs' MGM240S module, bringing Matter, Thread (802.15.4), and Bluetooth Low Energy to a single compact board.

| | |
|---|---|
| **Microcontroller** | Silicon Labs MGM240SD22VNA (32-bit Arm® Cortex®-M33 with DSP and FPU) |
| **Clock speed** | 78 MHz |
| **Memory** | 1536 kB Flash, 256 kB RAM |
| **Connectivity** | Matter, 802.15.4 (Thread / OpenThread), Bluetooth® Low Energy 5.3, Bluetooth® Mesh |
| **Antenna** | On-board 2.4 GHz |
| **Security** | Secure Vault™ High |
| **USB** | USB-C® (also used for debugging via SWD — no external probe needed) |
| **Digital I/O** | 22 pins |
| **Analog inputs** | 20 (12-bit resolution) |
| **DAC** | 4 (8–12-bit resolution) |
| **PWM pins** | 22 (max 5 simultaneously) |
| **External interrupts** | Available on all digital pins |
| **UART / I²C / SPI** | 2 / 2 / 2 |
| **User interface** | On-board RGB LED, user pushbutton |
| **Operating voltage** | 3.3 V |
| **Input voltage (VIN)** | 5 V |
| **Source / sink current per I/O** | 40 mA / 28 mA |
| **Operating temperature** | −40 °C to +85 °C |
| **Dimensions** | 45 × 18 mm |

Source: [Arduino Nano Matter — store.arduino.cc](https://store.arduino.cc/products/nano-matter), [docs.arduino.cc/hardware/nano-matter](https://docs.arduino.cc/hardware/nano-matter/).
